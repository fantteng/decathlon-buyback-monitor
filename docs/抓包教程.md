# 🎯 迪卡侬二手车监控 — 抓包教程（只需做一次）

> 目标：抓到迪卡侬小程序「二手童车」列表接口，交给监控脚本自动轮询。
> 全程约 10 分钟，做完把抓到的 cURL 发给 WorkBuddy 即可。

---

## 📦 第一步：安装 Fiddler Classic（抓包工具）

1. 打开官网下载页：https://www.telerik.com/fiddler/fiddler-classic
2. 填个邮箱 → 下载 `FiddlerSetup.exe` → 一路下一步安装
3. 安装完启动 Fiddler

## 🔐 第二步：开启 HTTPS 解密（关键）

1. 菜单 **Tools → Options → HTTPS** 标签页
2. 勾选 ✅ `Capture HTTPS CONNECTs`
3. 勾选 ✅ `Decrypt HTTPS traffic`
   - 弹窗一路点「是/Yes」，安装 Fiddler 根证书
4. 切到 **Connections** 标签页
5. 确认端口是 `8888`，勾选 ✅ `Allow remote computers to connect`（可选）
6. 点 OK，重启 Fiddler

> 💡 验证：随便用浏览器开个网页，Fiddler 左侧列表出现一堆记录且能看到内容 = 成功

## 📱 第三步：抓取小程序请求

1. 打开 **电脑版微信**（PC 微信的小程序流量默认走系统代理，Fiddler 能直接抓）
2. 在 Fiddler 左侧列表下方点一下 `All Processes` → 选中 `WeChatAppEx`（过滤噪音，可选）
3. 微信里打开 **迪卡侬小程序**：
   - 首页搜索框输入 **二手童车**（或点「当季品类 → 官方回购二手车」）
   - 城市选 **西安**
   - 依次点开几个门店、切换筛选（14寸、900系列）——让小程序把接口都请求一遍
4. 回到 Fiddler，左侧列表里找 **host 包含 `decathlon`** 的请求
5. 找到返回内容是 **车辆列表 JSON** 的那条（点它 → 右侧 `Inspectors → Raw/JSON` 能看到车辆数据，字段里出现价格、门店、成色等）

## 📤 第四步：把请求发给我（最简方式）

1. 在 Fiddler 左侧**右键**那条请求 → **Copy → Just cURL (bash)**
2. 直接粘贴发给 WorkBuddy

> ✅ 我会从 cURL 里解析出 URL、请求头（含 token）、请求体，自动填进 config.json 并测试接口。
>
> ⚠️ 如果 cURL 里含 token/authorization（登录凭证），注意别发给无关的人；token 过期后重新抓一次即可。

## 🧯 常见问题

| 症状 | 解法 |
|---|---|
| Fiddler 里全是 Tunnel to | HTTPS 解密没开好，回第二步重做 |
| 抓不到小程序请求 | 用 Proxifier 把 `WeChatAppEx.exe` 的流量指到 `127.0.0.1:8888` |
| 接口返回加密/乱码 | 换一条请求试试；还不行就联系我换 mitmproxy 方案 |
| 手机抓包 | 不推荐，PC 版简单得多 |
