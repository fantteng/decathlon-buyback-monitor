# 🖐️ 手把手抓包教程（零基础版）

> 工具换成 **Reqable**（国产、中文界面、一键配证书），全程只点鼠标，不用敲任何命令。
> **规则：一次只做一步。哪一步卡住了，截图发给 WorkBuddy，我帮你看。**

---

## 第 1 步：下载 Reqable（2 分钟）

1. 浏览器打开：**https://reqable.com/zh-CN/**
2. 点绿色按钮 **「下载」** → 选 **Windows**
3. 下载完成后双击安装 → 一路「下一步」→ 完成

✅ 完成标志：桌面上出现蓝色 Reqable 图标

---

## 第 2 步：打开 Reqable，一键装证书（1 分钟）

1. 打开 Reqable（第一次打开可能提示选网卡/模式，直接点「确定/默认」）
2. 看右上角或首页提示：**「安装根证书」** → 点它 → 弹窗一路「是(Y)」
3. 如果没看到提示：点菜单 **「设置 ⚙️」→「HTTPS 证书」→「安装到系统」**

✅ 完成标志：Reqable 主界面左上角有个 **「调试」大按钮**（像播放键 ▶）

---

## 第 3 步：开始抓包（点一下）

1. 点主界面的 **「调试」按钮**（▶）
2. 按钮变成红色/停止样式 = 正在抓包
3. **这个窗口先别关，最小化放着**

---

## 第 4 步：打开迪卡侬小程序（1 分钟）

1. 打开 **电脑版微信**（就是平时聊天那个）
2. 微信左下角有个 **「更多」→ 小程序面板**（或聊天列表顶部搜索）
3. 搜索 **迪卡侬** → 打开迪卡侬小程序
4. 小程序首页 **搜索框** 输入 **二手童车** → 进入二手车页面
5. 城市选 **西安**
6. **随便点开 2~3 家门店**，再点一下 14寸 筛选（多操作几下，让数据都加载一遍）

✅ 完成标志：你能看到各门店的二手车列表

---

## 第 5 步：找到数据请求（关键一步）

1. 切回 Reqable（任务栏点它）
2. 请求列表里，点顶部 **筛选/搜索框**，输入：`decathlon`
3. 逐条点击看右侧内容，找一条：
   - 状态码 200
   - 右侧切到 **「响应/预览」** 能看到 **车辆信息**（出现门店名、价格、青玉/颜色等字样）
4. 找到后，在那条请求上 **右键 → 复制 → 复制为 cURL(bash)**

✅ 完成标志：剪贴板里有一大段以 `curl` 开头的文字
